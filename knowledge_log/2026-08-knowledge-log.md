    <tr>
      <td>远端只读监控（ls-remote）</td>
      <td>软件工程</td>
      <td>★★★</td>
      <td>`git ls-remote` 是只读取远端引用名单的轻量级观测工具，通过比较返回的提交哈希和历史哈希，就能在不下载仓库的情况下判断分支是否移动。</td>
      <td>下一次可以深入 `git fetch` 与对象传输：fetch 会把缺失的提交和文件树下载到本地，从而让监控从“只知道 ref 变了”升级为“能查看提交信息、作者、文件列表和 diff”，并讨论如何在权限与可观测性之间做权衡。</td>
    </tr>
    <tr>
      <td>待确认变化线索</td>
      <td>软件工程</td>
      <td>★★★★</td>
      <td>待确认变化线索是指工作区中存在未提交或未跟踪的改动，但这些改动无法用 Git 元数据证明发生时间和完成状态，所以只能记为“当前待确认”，不能当作已确认的历史事实。</td>
      <td>下一次可以深入讲解如何设计跨日工作回顾的证据链：结合 Git 提交记录、自动化测试日志、文件系统元数据和外部系统记录，把待确认线索逐步升级为可信的事实。</td>
    </tr>
